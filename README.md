# Kat

  <img src="./icon.jpeg" alt="Kat logo" width="512" />
</p>

Kat is a high-performance, asset inventory tool for developers. It scans your project to catalog images, exact deep metadata (including AI generation signatures), detect duplicates, and generate beautiful insights.

## Features

- **🚀 Furious Speed**: Parallel scanning powered by `rayon`, checking thousands of assets in seconds.
- **✨ AI Detection**: Detects hidden signatures from **Midjourney**, **Adobe Firefly**, **DALL-E**, **Stable Diffusion**, and **C2PA** content credentials.
- **🧠 Deep Metadata**: Extracts EXIF, XMP, IPTC, and ICC profiles automatically.
- **🛡️ Smart Defaults**: Ignores `node_modules`, `.git`, and other clutter by default.
- **📦 Zero Config**: Just run `kat scan` to get a full JSON and Markdown report.

## Quick start

```bash
# Install from source
cargo install --path . --force

# Scan current directory (Auto-generates assets.json & assets.md)
kat scan

# Inspect a single file for AI signatures
kat info path/to/image.png

# Surface duplicates
kat duplicates
```

## Why Kat?

- **Performance**: Uses buffered I/O and parallel iterators to saturate your SSD.
- **Intelligence**: Don't just list files; understand them. Know if an image was generated by AI or modified by Photoshop.
- **Experience**: Beautiful terminal output with progress bars, ASCII art, and colored warnings.
